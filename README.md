## 技術

- [Pannellum 2.5.6](https://pannellum.org/) 已 vendored 至 `assets/`，無需 CDN，離線可用
- 全景圖 2048×1024（2:1 等距長方投影），縮圖 320×160
- 純靜態網站，直接由 GitHub Pages 提供

## 本機預覽

```bash
python3 -m http.server 8000
```

然後開 http://localhost:8000/ 。請勿用 `file://` 直接開檔，WebGL 會因 origin 限制失敗。

## 備註

全景圖為 AI 生成之設計示意，左右接縫位置可能存在輕微錯位，屬已知限制。
